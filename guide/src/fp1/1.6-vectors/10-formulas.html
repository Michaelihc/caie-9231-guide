Formulas line $\V r=\V a+\lambda\V b$, plane $\V r\cdot\V n=p$

F1
Scalar productMF19 $$\V a\cdot\V b=a_1b_1+a_2b_2+a_3b_3=|\V a||\V b|\cos\theta$$

$\V a\cdot\V b=0$ ⇔ ⊥.

F2
Vector product
$$\V a\times\V b=\cvec{a_2b_3-a_3b_2}{a_3b_1-a_1b_3}{a_1b_2-a_2b_1},\qquad |\V a\times\V b|=|\V a||\V b|\sin\theta$$

Answer ⊥ both. $\V b\times\V a=-\V a\times\V b$. $=\V 0$ ⇔ ∥.

Top = 2nd·3rd − 3rd·2nd. Next rows: shift indices 1 → 23, 31, 12.

Size = size of $\V a$ × size of $\V b$ × sin(angle). Points ⊥ both.

No quick derivation. Learn it. Memory aid: $\begin{vmatrix}\V i&\V j&\V k\\a_1&a_2&a_3\\b_1&b_2&b_3\end{vmatrix}$, middle term minus.

F3
Line, cartesian
$$\V r=\V a+\lambda\V b\iff\frac{x-a_1}{b_1}=\frac{y-a_2}{b_2}=\frac{z-a_3}{b_3}\;(=\lambda)$$

Some $b_i=0$ ⇒ drop that fraction, write that coord fixed, e.g. $z=a_3$.

Each coord: (coord − point's coord) ÷ direction's coord. All three equal.

  1. Split into rows: $x=a_1+\lambda b_1$, $y=a_2+\lambda b_2$, $z=a_3+\lambda b_3$.
  2. Make $\lambda$ subject of each: $\lambda=\frac{x-a_1}{b_1}$, …
  3. All $=\lambda$ ⇒ set equal.

Back to vector form: set each fraction $=\lambda$, solve for $x,y,z$.

F4
Plane, 3 forms
$$n_1x+n_2y+n_3z=p\iff\V r\cdot\V n=p,\quad p=\V a\cdot\V n\qquad\V r=\V a+\lambda\V b+\mu\V c\;\Rightarrow\;\V n=\V b\times\V c$$

$\V a$ = any point in plane. $\V n$ = normal.

Normal · (any point in plane) = same number every time.

Normal = cross of 2 directions lying in plane.

  1. Known point $A$, any point $R$ in plane. $\AB{AR}=\V r-\V a$ lies in plane.
  2. Normal ⊥ everything in plane ⇒ $(\V r-\V a)\cdot\V n=0$ ⇒ $\V r\cdot\V n=\V a\cdot\V n$.
  3. Put $\V r=(x,y,z)$, expand dot ⇒ $n_1x+n_2y+n_3z=p$.
  4. $\V n$ ⊥ both $\V b,\V c$ ⇒ $\V n=\V b\times\V c$ (F2).
F5
Distance point $(x_0,y_0,z_0)$ to plane
$$d=\frac{|n_1x_0+n_2y_0+n_3z_0-p|}{\sqrt{n_1^2+n_2^2+n_3^2}}$$

From O: $|p|/|\V n|$. Same sign inside $|\,|$ for two points ⇒ same side.

Plug point into plane's left side. Subtract right side. Make positive. ÷ length of normal.

  1. Walk from $Q$ along normal: $\V r=\V q+t\V n$.
  2. Hit plane: $(\V q+t\V n)\cdot\V n=p$ ⇒ $t=\dfrac{p-\V q\cdot\V n}{|\V n|^2}$.
  3. Distance $=|t||\V n|$.

Same $t$ gives foot and reflection: P4.

F6
Distance point $Q$ to line
$$d=\frac{|(\V q-\V a)\times\V b|}{|\V b|}$$

Cross (point-on-line → $Q$) with direction. Take length. ÷ length of direction.

  1. Parallelogram on $\AB{AQ}$ and $\V b$.
  2. Area = $|\AB{AQ}\times\V b|$. Area = base × height = $|\V b|\,d$.
  3. Equal ⇒ $d=|\AB{AQ}\times\V b|/|\V b|$.

No cross product: P5. Point $\V a+\lambda\V b$, solve $\AB{QP}\cdot\V b=0$, $d=|\AB{QP}|$.

F7
Shortest distance, skew lines
$$\V r=\V a+\lambda\V b,\ \V r=\V c+\mu\V d:\qquad d=\frac{|(\V c-\V a)\cdot(\V b\times\V d)|}{|\V b\times\V d|}$$

$d=0$ ⇒ lines meet.

Join any point on $l_1$ to any point on $l_2$. Dot with common normal ($\V b\times\V d$). Make positive. ÷ length of normal.

  1. Shortest $PQ$ ⊥ both lines ⇒ ∥ $\V b\times\V d$.
  2. Point on $l_1$ + $k$·normal = point on $l_2$: $\V a+\lambda\V b+k(\V b\times\V d)=\V c+\mu\V d$.
  3. 3 linear eqns ⇒ $\lambda,\mu,k$.
  4. Distance $=|k||\V b\times\V d|$.

Bonus: $\lambda,\mu$ give $P,Q$ ⇒ common ⊥ (P9).

F8
Angles (acute)
$$\text{line,line: }\cos\theta=\frac{|\V b\cdot\V d|}{|\V b||\V d|}\quad\text{plane,plane: }\cos\theta=\frac{|\V n_1\cdot\V n_2|}{|\V n_1||\V n_2|}\quad\text{line,plane: }\sin\theta=\frac{|\V b\cdot\V n|}{|\V b||\V n|}$$

Line, plane uses sin: $\V n$ is ⊥ plane. Abs value ⇒ acute.

cos(angle) = |dot| ÷ (length × length).

Planes: use normals. Line with plane: use sin, because normal sits 90° off plane.

  1. All from F1 (in MF19): $\cos\theta=\V u\cdot\V v\,/\,(|\V u||\V v|)$.
  2. Planes: tilt between planes = tilt between normals ⇒ use $\V n_1,\V n_2$.
  3. Line, plane: F1 with $\V b,\V n$ gives $\varphi$ = angle to normal. Plane is 90° off normal ⇒ $\theta=90^\circ-\varphi$ ⇒ $\sin\theta=\cos\varphi$.
  4. Abs value on top ⇒ acute.
F9
Area, volume
$$\triangle ABC=\tfrac12|\AB{AB}\times\AB{AC}|\qquad V_{ABCD}=\tfrac16\left|\AB{AB}\cdot(\AB{AC}\times\AB{AD})\right|$$

Parallelogram: $|\AB{AB}\times\AB{AC}|$. Tetrahedron also $\tfrac13\times\text{base}\times\text{height}$ (Q usually gives this).

Triangle = half length of cross of 2 sides from one corner.

Tetrahedron = ⅙ × |side · (side × side)|, 3 sides from one corner.

  1. Triangle: $\tfrac12 uv\sin\theta$ and $|\V u\times\V v|=|\V u||\V v|\sin\theta$ ⇒ $\tfrac12|\AB{AB}\times\AB{AC}|$.
  2. Tetrahedron $=\tfrac13\times$ base $\times$ height. Base $ACD=\tfrac12|\AB{AC}\times\AB{AD}|$.
  3. Height = distance $B$ to plane $ACD$ = $\dfrac{|\AB{AB}\cdot(\AB{AC}\times\AB{AD})|}{|\AB{AC}\times\AB{AD}|}$ (F5 idea).
  4. Multiply: $\tfrac13\cdot\tfrac12\cdot$ ⇒ $\tfrac16|\AB{AB}\cdot(\AB{AC}\times\AB{AD})|$.
F10
Point dividing $AB$ in ratio $\lambda:\mu$
$$\V p=\frac{\mu\V a+\lambda\V b}{\lambda+\mu}$$

Was in old MF10. Gone from MF19.

Start at $A$. Go $\frac{\lambda}{\lambda+\mu}$ of the way to $B$.

  1. $\V p=\V a+\frac{\lambda}{\lambda+\mu}(\V b-\V a)$.
  2. Collect $\V a$ and $\V b$ ⇒ $\frac{\mu\V a+\lambda\V b}{\lambda+\mu}$.

Check: $\lambda=\mu$ ⇒ midpoint.
