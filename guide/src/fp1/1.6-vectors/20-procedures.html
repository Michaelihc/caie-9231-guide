Procedures

P1
Plane equationuses F2 F3
  1. Get 1 point $A$ in plane + 2 non-∥ dirs $\V u,\V v$ in plane.
  2. $\V n=\V u\times\V v$. Cancel common factor.
  3. $p=\V n\cdot\V a$.
  4. Write $n_1x+n_2y+n_3z=p$.
  5. Check: 2nd known point fits.
Where $\V u,\V v$ come from
  • 3 points $A,B,C$: $\V u=\AB{AB}$, $\V v=\AB{AC}$.
  • Line $\V a+\lambda\V b$ + point $Q$: $\V u=\V b$, $\V v=\V q-\V a$.
  • 2 lines that meet: $\V u=\V b_1$, $\V v=\V b_2$.
  • 2 ∥ lines: $\V u=\V b$, $\V v=\V a_2-\V a_1$.
  • Line + ∥ to vector $\V w$: $\V u=\V b$, $\V v=\V w$.
  • Line + ⊥ to plane with normal $\V m$: $\V u=\V b$, $\V v=\V m$.
Skip the cross product
  • ∥ to plane $\Pi$: same $\V n$ as $\Pi$.
  • ⊥ to line with dir $\V b$: $\V n=\V b$.
  • ⊥ to planes $\Pi_1,\Pi_2$: $\V n=\V n_1\times\V n_2$.
Contains line of intersection of $\Pi_1,\Pi_2$ + point $Q$

Plane $=(\V n_1\cdot\V r-p_1)+k(\V n_2\cdot\V r-p_2)=0$. Sub $Q$ ⇒ $k$. Or: P7 for line, then line + point.

Want parametric form

$\V r=\V a+\lambda\V u+\mu\V v$ directly. No $\V n$ needed.

P2
Convert plane formuses F2 F3
  1. Parametric → cartesian: $\V n=\V b\times\V c$, $p=\V a\cdot\V n$.
  2. Cartesian → $\V r\cdot\V n=p$: $\V n$ = coefficients, $p$ = RHS.
  3. Cartesian → parametric: find 3 points $A,B,C$ (set 2 coords, solve 3rd). $\V r=\V a+\lambda\AB{AB}+\mu\AB{AC}$.
Coefficient is 0, e.g. $x+2y=4$

Missing var free ⇒ $\V k$ lies in plane. Use $\V k$ as one dir. Plane ∥ $z$-axis.

Parametric answer looks different from mark scheme

Fine if same plane: check its $\V b\times\V c$ ∥ your $\V n$ and its $\V a$ fits.

P3
Line vs plane: meet, ∥, or inuses F1 F4
  1. Line $\V a+\lambda\V b$, plane $\V r\cdot\V n=p$. Find $\V b\cdot\V n$.
  2. $\V b\cdot\V n\ne0$ ⇒ meet once. Sub line into plane: $\lambda=\dfrac{p-\V a\cdot\V n}{\V b\cdot\V n}$. Put $\lambda$ back ⇒ point.
  3. $\V b\cdot\V n=0$ ⇒ line ∥ plane. Test $\V a\cdot\V n$: $=p$ ⇒ line lies in plane. $\ne p$ ⇒ never meet, gap = F4 at $A$.
Plane given parametric

P2 to cartesian first. Or set $\V a+t\V b=\V c+\lambda\V d+\mu\V e$, 3 eqns, 3 unknowns.

P4
Foot of ⊥ from point $Q$ to planeuses F4
  1. Line from $Q$ along normal: $\V r=\V q+t\V n$.
  2. Sub into plane: $t=\dfrac{p-\V q\cdot\V n}{|\V n|^2}$.
  3. Foot $N$: $\V q+t\V n$.
  4. Distance $QN=|t||\V n|$ (same as F4).
Reflection of $Q$ in plane

$\V q'=\V q+2t\V n$ (same $t$).

Foot from origin

$\V q=\V 0$ ⇒ $t=p/|\V n|^2$, $N=t\V n$.

Plane given by 3 points

P1 first for $\V n,p$.

P5
Foot of ⊥ from point $Q$ to lineuses F1 F5
  1. General point on line $P=\V a+\lambda\V b$.
  2. $\AB{QP}=\V a+\lambda\V b-\V q$.
  3. Solve $\AB{QP}\cdot\V b=0$ ⇒ $\lambda$.
  4. Foot = $P$ at that $\lambda$. Distance = $|\AB{QP}|$.
Distance only

F5, faster.

Reflection of $Q$ in line

$\V q'=2\V p-\V q$ ($P$ = foot, midpoint of $QQ'$).

Line through $A$ and $C$

$\V a=\AB{OA}$, $\V b=\AB{AC}$.

P6
Angleuses F1 F7
  1. Pick vectors: line ⇒ dir $\V b$. Plane ⇒ normal $\V n$.
  2. Line, line or plane, plane ⇒ cos rule of F7. Line, plane ⇒ sin rule.
  3. Keep $|\,\cdot\,|$ on top ⇒ acute.
Planes given by points (e.g. $ABC$, $ABD$)

P1 step 2 for each normal. No need for $p$.

Line, plane done with cos by mistake

cos gives angle $\varphi$ to normal. Answer $\theta=90^\circ-\varphi$.

P7
Line of intersection of 2 planesuses F2
  1. Dir $\V d=\V n_1\times\V n_2$.
  2. Point: pick coord where $\V d$ entry ≠ 0. Set that coord $=0$. Solve 2 plane eqns for other 2.
  3. $\V r=\V a+t\V d$.
  4. Check: point fits both planes.
Why pick coord with $d_i\ne0$

$d_3=0$ ⇒ $z$ fixed on whole line. Setting $z=0$ ⇒ no solution (unless that fixed value is 0).

No cross product

Set $z=t$. Solve both eqns for $x,y$ in $t$. Read $\V a,\V d$ off.

$\V n_1\times\V n_2=\V 0$

Planes ∥. No line. Same eqn up to scale ⇒ same plane.

Plane given parametric

P2 to cartesian first.

P8
Two lines: meet, ∥, or skewuses F6
  1. $\V b=k\V d$? ⇒ ∥. ($\V a$ on other line ⇒ same line.) Stop.
  2. Else set $\V a+\lambda\V b=\V c+\mu\V d$ ⇒ 3 eqns.
  3. Solve 2 eqns ⇒ $\lambda,\mu$. Test 3rd.
  4. 3rd fits ⇒ meet, point $=\V a+\lambda\V b$. Fails ⇒ skew.
Quick test

$(\V c-\V a)\cdot(\V b\times\V d)=0$ ⇔ coplanar ⇒ meet (if not ∥).

P9
Skew lines: shortest distance + common ⊥uses F2 F6
  1. $P=\V a+\lambda\V b$ on $l_1$, $Q=\V c+\mu\V d$ on $l_2$.
  2. $\AB{PQ}=\V c+\mu\V d-\V a-\lambda\V b$.
  3. $\AB{PQ}\cdot\V b=0$ and $\AB{PQ}\cdot\V d=0$ ⇒ solve for $\lambda,\mu$.
  4. Get $P,Q$. Distance $=|\AB{PQ}|$.
  5. Common ⊥: $\V r=\V p+t(\V b\times\V d)$.
Distance only

F6. Use it to check $|\AB{PQ}|$ too.

Other way to step 3

$\AB{PQ}=k(\V b\times\V d)$ ⇒ 3 linear eqns in $\lambda,\mu,k$.

Plane containing $l_1$ + common ⊥

P1 with point $\V a$, $\V u=\V b$, $\V v=\V b\times\V d$.

Lines ∥, not skew

No single common ⊥. Distance = F5 with $Q=C$.

Lines given as $AB$ and $CD$

$\V a=\AB{OA}$, $\V b=\AB{AB}$, $\V c=\AB{OC}$, $\V d=\AB{CD}$.

P10
Area and volumeuses F8 F4
  1. Make edge vectors from 1 vertex: $\AB{AB},\AB{AC}(,\AB{AD})$.
  2. Triangle: $\tfrac12|\AB{AB}\times\AB{AC}|$.
  3. Tetrahedron: $\tfrac16|\AB{AB}\cdot(\AB{AC}\times\AB{AD})|$.
Q gives $V=\tfrac13\times$ base $\times$ height

Base = triangle $ABC$. Height = F4 from $D$ to plane $ABC$ (P1).

Triple product = 0

$A,B,C,D$ coplanar. Volume 0.
